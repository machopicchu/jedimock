Welcome to JediMock
Dev & QA Toolkit — mock APIs in seconds
1
Set the URL to intercept
Enter part of the API URL — e.g. /api/users or use wildcards like /api/users/* for dynamic IDs.
2
Choose your target & paste JSON
Pick Response, Request, or Both. Paste your JSON and click Load JSON — or use Import cURL to extract the URL and body directly from a DevTools Network tab copy.
3
Edit fields in the tree
Click any value in the tree to edit it inline. Change whatever you need — status, names, flags, nested objects.
4
Generate & paste the script
Click Generate Script, copy it, then paste into your browser's DevTools console. Every matching request is intercepted automatically. Refresh the page to deactivate.
5
Power features
Use Response Rules to return different responses per call count. Enable Fallback mode to return your mock if the server never responds. Try Async ID mode for job polling or webhook flows.
